Hide Manage Databases Link

Clean and secure login: hide the Manage Databases link on the Odoo 16 login page and throws up 404 error if user tries to access web/database/manager. Works even when list_db = True, allowing modules like OCA's auto_backup to operate normally while keeping the login UI tidy.

Price: $13 (OPL-1)

Features

  • Hide "Manage Databases" link from the login screen
  • Block access to "web/database/manager"
  • Compatible with Odoo 16 Community & Enterprise
  • Non-destructive: hides via CSS to avoid JS breakage
  • Works while list_db = True so backup tasks continue
  • OPL-1 licensed

How it works

The module injects a small CSS rule into the layout so the anchor pointing to /web/database/manager is hidden visually. This approach keeps the DOM intact and prevents JavaScript errors that can occur if elements are removed.

Installation

  1. Copy the unzipped folder hide_db_manager_websafe into your Odoo addons folder.
  2. Restart Odoo server.
  3. Apps → remove 'Apps' filter → Update App List → Install module.
